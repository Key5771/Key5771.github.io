## Tuist
Tuist는 Xcode 프로젝트 생성과 관리를 자동화하여 개발 과정을 더욱 효율적으로 만들어주는 강력한 도구

### Tuist 설치하기
Tuist는 mise를 통해 설치할 수 있습니다.

1. mise 설치

```bash
$ curl https://mise.run | sh
$ ~/.local/bin/mise --version
2025.11.8 macos-arm64 (a1b2d3e 2025-11-26)
```

2. mise 활성화
터미널 환경에 맞는 명령어 입력

```bash
# note this assumes mise is located at ~/.local/bin/mise
# which is what https://mise.run does by default
echo 'eval "$(~/.local/bin/mise activate bash)"' >> ~/.bashrc
echo 'eval "$(~/.local/bin/mise activate zsh)"' >> ~/.zshrc
echo '~/.local/bin/mise activate fish | source' >> ~/.config/fish/config.fish
echo '~/.local/bin/mise activate pwsh | Out-String | Invoke-Expression' >> ~/.config/powershell/Microsoft.PowerShell_profile.ps1
```

3. mise로 tuist 설치

```bash
mise install tuist            # Install the current version specified in .tool-versions/.mise.toml
mise install tuist@x.y.z      # Install a specific version number
mise install tuist@3          # Install a fuzzy version number
```

4. tuist를 설치하고 mise로 해당 버전은 use를 통해 활성화

```bash
mise use tuist@x.y.z          # Use tuist-x.y.z in the current project
mise use tuist@latest         # Use the latest tuist in the current directory
mise use -g tuist@x.y.z       # Use tuist-x.y.z as the global default
mise use -g tuist@system      # Use the system's tuist as the global default
```

5. tuist 버전 확인

```bash
tuist version
// 4.40.0
```

참고사항

- Homebrew를 이용해서도 설치할 수 있음

```bash
brew tap tuist/tuist
brew install --formula tuist
brew install --formula tuist@x.y.z
```

### Tuist 프로젝트 생성 및 설정

1. 프로젝트 디렉토리 생성

```bash
mkdir MyApp
cd MyApp
```

2. init 명령어를 통해 프로젝트 생성

- 아래 명령어를 입력하면 v3에서는 기본적으로 UIKit 프로젝트가 생성되지만, v4에서는 기본적으로 SwiftUI 프로젝트가 생성됩니다.

```bash
tuist init --platform ios
```

3. 프로젝트 수정

```bash
tuist edit
```

4. 프로젝트에 맞게 Project.swift 설정

```swift
import ProjectDescription

let project = Project(
    name: "MyApp",
    targets: [
        .target(
            name: "MyApp",
            destination: .iOS,
            product: .app,
            bundleId: "dev.tuist.MyApp",
            infoPlist: .extendingDefault(
                with: [
                    "UILaunchScreen": [
                        "UIColorName": "",
                        "UIImageName": ""
                    ],
                ]
            ),
            sources: ["MyApp/Sources/**"],
            resources: ["MyApp/Resources/**"],
            dependencies: []
        ),
        .target(
            name: "MyAppTests",
            destination: .iOS,
            product: .unitTests,
            bundleId: "dev.tuist.MyAppTests",
            infoPlist: .default,
            sources: ["MyApp/Tests/**"],
            resources: [],
            dependencies: [.target(name: "MyApp")]
        ),
    ]
)
```

### Manifests

Tuist는 Project와 Workspace를 정의하고 생성 프로세스를 구성하는 주요 방법으로 Swift를 기본으로 사용합니다.
이를 Tuist 문서에서는 Manifest 파일이라고 합니다.

Swift를 사용하면서 컴파일러를 활용하고 컨텐츠의 정확성을 검증하며 여러 Manifest 파일에서 코드를 재사용할 수 있습니다.
Xcode는 구문 강조, 자동 완성 및 유효성 검사를 통해 편리한 환경을 제공합니다.

#### Project.swift

Project.swift는 Xcode 프로젝트를 선언합니다.
Project.swift는 파일이 있는 디렉토리의 name 속성에 지정된 이름으로 생성됩니다.

```swift
// Project.swift
let project = Project(
    name: "App",
    targets: [
        // ...
    ]
)
```

#### Workspace.swift

기본적으로 Tuist는 생성되는 프로젝트와 해당 프로젝트가 종속된 프로젝트를 포함하는 Xcode Workspace를 생성합니다.
프로젝트를 추가하거나 파일 및 그룹을 포함하도록 작업 공간을 지정하려면 Workspace.swift를 정의하면 됩니다.

```swift
// Workspace.swift
import ProjectDescription

let workspace = Workspace(
    name: "App-Workspace",
    projects: [
        "./App",        // Path to directory containing the Project.swift file
    ]
)
```

#### Tuist.swift

Tuist는 프로젝트 구성을 간소화하기 위해 합리적인 기본값을 제공합니다.
하지만 프로젝트 루트에 Tuist.swift를 정의하여 구성을 사용자가 지정할 수 있습니다.
이는 Tuist가 프로젝트의 루트를 결정하는데 사용됩니다.

```swift
import ProjectDescription

let tuist = Tuist(
    project: .tuist(generationOptions: .option(enforceExplicitDependencies: true))
)
```

### Directory 구조

Tuist 프로젝트는 일반적으로 Xcode 프로젝트를 대체하는데 사용되지만, 이 사용 사례에만 국한되지는 않습니다.
Tuist 프로젝트는 SPM 패키지, 템플릿, 플러그인 등 다른 유형의 프로젝트를 생성하는 데에도 사용됩니다.

#### Standard Tuist projects

Tuist 프로젝트는 Tuist에서 생성하는 가장 일반적인 프로젝트 유형입니다.
앱, 프레임워크, 라이브러리 등을 빌드하는데 사용됩니다.
Xcode 프로젝트와 달리 Tuist 프로젝트는 Swift로 정의되어 있어 더욱 유연하고 유지보수에 쉽습니다.
또한, Tuist 프로젝트는 선언적이므로 이해하고 추론하기 쉽습니다.

```bash
Tuist.swift
Tuist/
  Package.swift
  ProjectDescriptionHelpers/
Projects/
  App/
    Project.swift
  Feature/
    Project.swift
Workspace.swift
```

- **Tuist directory**: 이 디렉토리는 두 가지 목적을 가지고 있습니다. 
  - 첫째, 프로젝트의 루트 위치를 나타냅니다. 이를 통해 프로젝트 루트를 기준으로 경로를 설정하고 프로젝트 내 모든 디렉토리에서 Tuist 명령어를 실행할 수 있습니다. 
  - 둘째, 다음 파일들을 저장하는 컨테이너입니다.
    - **ProjectDescriptionHelpers**: 이 디렉토리에는 모든 Manifest 파일에서 공유되는 Swift 코드가 들어있습니다. Manifest 파일은 ProjectDescriptionHelpers를 가져와서 이 디렉토리에 정의된 코드를 사용할 수 있습니다. 코드 공유는 중복을 방지하고 프로젝트 전체의 일관성을 유지하는데 도움이 됩니다.
    - **Package.swift**: 이 파일에는 Tuist가 Xcode 프로젝트 및 target(예: CocoaPods)을 사용하여 통합할 수 있는 Swift 패키지 종속성이 포함되어 있습니다. 이러한 종속성은 구성 및 최적화가 가능합니다.

- **Root Directory**: Tuist 디렉토리도 포함하는 프로젝트의 루트 디렉토리입니다.
  - **Tuist.swift**: 이 파일에는 모든 project, target 및 environments에서 공유되는 Tuist 구성이 포함되어 있습니다. 예를 들어, 스키마 자동 생성을 비활성화 하거나 프로젝트의 배포 대상을 정의하는데 사용할 수 있습니다.
  - **Workspace.swift**: 이 Manifest는 Xcode workspace를 나타냅니다. 다른 프로젝트를 그룹화 하는데 사용되며 추가 파일과 스키마를 추가할 수도 있습니다.
  - **Project.swift**: 이 Manifest는 Xcode 프로젝트를 나타냅니다. 프로젝트에 포함된 target과 해당 target의 종속성을 정의하는데 사용됩니다.
